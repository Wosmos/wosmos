## 👨‍💻 About Me

I build **production web applications and systems-level software end-to-end** — concurrent backends in Go, modern frontends with Next.js, and security-first architecture. I like owning every layer: schema design, backend services, client apps, and deployment.

- 🔐 Built **[Zcrypt](https://github.com/Wosmos/zcrypt)** — a zero-knowledge encrypted storage platform (AES-256-GCM, one Go backend, three clients)
- ⚡ Shipped a **concurrent Go WebSocket** chat system across web and mobile
- 🧰 Ship & operate real products — live domains, npm/Homebrew releases, CI pipelines
- 🌱 Currently deep in **Go concurrency, cloud-native systems, and end-to-end encryption**
- 💬 Open to **software engineering roles and freelance projects**
